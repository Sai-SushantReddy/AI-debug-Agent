# AI Debug Agent

An agentic AI-powered debugging assistant built using FastAPI and LangGraph.

## Features

- Multi-agent debugging workflow
- Repository-aware context retrieval
- Deterministic debugging tools
- LLM-powered fix generation
- Automatic syntax validation
- Critic agent for fix review
- Reflection-based retry mechanism
- Structured debugging reports

## Tech Stack

- FastAPI
- LangGraph
- LangChain
- Groq LLM
- HuggingFace Embeddings
- ChromaDB
- Python
